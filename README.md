# League Item Advisor

A React and TypeScript foundation for a situational League of Legends item advisor.
The current page is a placeholder. Match data, recommendations, and the game overlay
will be added in later steps of [PLAN.md](PLAN.md).

## Run locally

Install Node.js 20.19+ or 22.12+ (including Node.js 24) and npm, then run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To check the production build, run:

```sh
npm run build
```

The production files are written to `dist/`.
